# Receptionist Activity Detection

A Python computer vision pipeline that monitors front-desk receptionist workstation occupancy from CCTV footage using **YOLOv8 person detection**, **polygon ROI occupancy analysis**, and **temporal activity classification**.

It produces an annotated MP4 video, activity timeline CSV, and audit reports (JSON + TXT).

---

## How It Works

The pipeline runs in **two passes**:

**Pass 1 — Analysis:** Reads frames, detects people with YOLOv8, checks if they are inside the workstation ROI polygon, and classifies the activity state:
- `ACTIVE` — person inside ROI continuously for ≥ 1.0s
- `AWAY` — ROI empty continuously for ≥ 2.0s
- `UNKNOWN` — initial unconfirmed state

**Pass 2 — Rendering:** Replays the precomputed observations frame by frame, draws the ROI boundary (red polygon), bounding boxes only for people inside the ROI (green), and a HUD overlay showing live status, occupancy count, elapsed time, and CCTV timestamp. Saves the final MP4.

## Setup Instructions

### Prerequisites

- Python 3.11
- [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) *(optional — used for reading the on-screen CCTV timestamp; falls back to interpolation if not installed)*

---

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Receptionist_Activity_Detection_Poc.git
cd Receptionist_Activity_Detection_Poc
```

---

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it:

- **Windows:**
  ```bash
  .venv\Scripts\activate
  ```
- **macOS / Linux:**
  ```bash
  source .venv/bin/activate
  ```

---

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 4. Add Your Input Video

Place your CCTV footage at:

```
input/input_video.mp4
```

---

### 5. (Optional) Install Tesseract OCR

Tesseract is used to read the on-screen DVR timestamp from the footage. If it is not installed, the pipeline automatically falls back to time interpolation from the configured `CCTV_START_DATETIME`.

- **Windows:** Download and install from [UB-Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki). Default install path: `C:\Program Files\Tesseract-OCR\tesseract.exe`
- **macOS:** `brew install tesseract`
- **Linux:** `sudo apt install tesseract-ocr`

Update `config.py` if your Tesseract path differs:

```python
TESSERACT_CMD = r"C:\Program Files\Tesseract-OCR\tesseract.exe"
```

---

### 6. Configure ROI and Settings *(if needed)*

Open `config.py` to adjust the workstation ROI polygon, confidence threshold, and confirmation timings for your specific camera angle:

```python
# Workstation polygon ROI — calibrate to your camera
ROI_POINTS = [
    [296, 307],
    [501, 223],
    [629, 477],
    [380, 477],
]

# Confidence and overlap
CONFIDENCE_THRESHOLD = 0.25
ROI_MIN_OVERLAP_RATIO = 0.40

# Temporal thresholds
ACTIVE_CONFIRMATION_SECONDS = 1.0
AWAY_CONFIRMATION_SECONDS   = 2.0

# CCTV start datetime (used for timestamp interpolation fallback)
CCTV_START_DATETIME = "2026-06-18 09:34:30"
```

---

## Running the App

### Option A — Streamlit Web Dashboard *(recommended)*

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser. You can adjust ROI coordinates, confidence threshold, and confirmation timings from the sidebar — then click **Run Pipeline**.

### Option B — Command Line

```bash
python main.py
```

Runs the full pipeline and saves all outputs to the `output/` folder.

## Output Files

All outputs are saved to the `output/` directory:

| File | Description |
|------|-------------|
| `processed_reception_video.mp4` | Annotated video with ROI boundary, bounding boxes, and HUD overlay |
| `activity_timeline.csv` | Chronological activity intervals with start/end times and durations |
| `activity_summary.txt` | Executive summary report with totals and percentages |
| `activity_summary.json` | Machine-readable structured report |
